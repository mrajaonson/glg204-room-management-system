# pandoc

Converts Markdown files to PDF with PlantUML diagram support.

## Installation

### Dependencies

**Linux**

```shell
sudo apt install pandoc graphviz
```

**mac**

```shell
brew install pandoc graphviz libtool
```

## Usage

```shell
./pandoc/md2pdf.sh docs/input.md
./pandoc/md2pdf.sh docs/input.md output.pdf
```

### Options

| Option                | Default                | Description                                   |
|-----------------------|------------------------|-----------------------------------------------|
| `--plantuml-jar PATH` | `pandoc/plantuml.jar`  | Path to `plantuml.jar`                        |
| `--defaults PATH`     | `pandoc/defaults.yaml` | Pandoc defaults YAML                          |
| `--toc-depth N`       | `4`                    | TOC depth when auto-inserting                 |
| `--engine ENGINE`     | `xelatex`              | PDF engine: `xelatex`, `pdflatex`, `lualatex` |
| `--keep-diagrams`     | off                    | Keep generated PNG files after build          |

### TOC placement

Place `\tableofcontents` anywhere in the Markdown to control where the TOC appears. If absent, it is prepended automatically.

### PlantUML

Fenced ` ```plantuml ``` ` blocks are replaced by the PNGs generated by `plantuml.jar` before pandoc runs. Generated PNGs are deleted after the PDF is built (use `--keep-diagrams` to retain them).

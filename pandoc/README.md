# pandoc

Converts Markdown files to PDF with PlantUML diagram support.

## Installation

### Dependencies

```shell
# linux
sudo apt install pandoc graphviz

# mac
brew install pandoc graphviz libtool
```

**PlantUML** — download `plantuml.jar` from https://plantuml.com/en/download and place it at `pandoc/plantuml.jar`.

## Usage

```shell
./pandoc/md2pdf.sh docs/input.md
./pandoc/md2pdf.sh docs/input.md output.pdf
```

### TOC placement

Place `\tableofcontents` anywhere in the Markdown to control where the TOC appears.

### PlantUML

Fenced ` ```plantuml ``` ` blocks are replaced by the PNGs generated by `plantuml.jar` before pandoc runs. Generated PNGs are deleted after the PDF is built.
